
# SOAP不足確認（Brainstorming）検証パターン
**入力形式：訪問記録全文**

## 目的

本機能は、利用者の訪問記録全文からAIがSOAP下書きを生成した後、
SOAPの不足・曖昧さ・矛盾・判断根拠不足を検出し、
追加質問を提示できることを検証する。

---

# TC-001 判断根拠が十分なケース

## 入力（訪問記録全文）

```text
本日14時に利用者宅を訪問した。

利用者は
「最近あまり食欲がなく、朝も食べていない」
と話した。

冷蔵庫を確認すると、
食材が少なく、賞味期限切れの食品が複数あった。

次回訪問時に食事状況を確認する予定である。
```

## AI生成SOAP

```text
S
最近食欲がなく、朝も食べていない。

O
冷蔵庫内の食材が少なく、期限切れ食品が複数あった。

A
栄養状態が悪化している可能性がある。

P
次回訪問時に食事状況を確認する。
```

## 期待結果

- Aの根拠不足は検出しない
- 以下のみ質問する
    - 次回予定日
    - 担当者
    - 確認方法

# TC-005 曖昧表現

## 入力（訪問記録全文）

```text
最近夜眠れず、
少し食欲も落ちている。

必要なら配食サービスを検討したい。
```

## AI生成SOAP

```text
S
最近眠れていない。
少し食欲が落ちている。

P
必要であれば配食サービスを検討する。
```

## 期待結果

### 検出

- 「最近」が曖昧
- 「少し」が曖昧
- 「必要であれば」が曖昧

### 質問

- 眠れない状態はいつ頃からですか。
- 食欲はどの程度低下していますか。
- どのような状態になれば配食サービスを検討しますか。

# TC-012 E2E

## 入力（訪問記録全文）

```text
本日14時訪問。

本人は
「最近夜眠れず食欲もない」
と話した。

冷蔵庫の食材は少なく、
体重は1か月で3kg減少していた。

次回訪問で確認予定。
```

## AI生成SOAP

```text
S
最近眠れない。
食欲がない。

O
食材が少ない。
体重3kg減少。

A
栄養状態が悪化している可能性がある。

P
次回確認する。
```

## 期待結果

検出

- Pの日付不足
- Pの担当者不足
- Pの確認方法不足

質問

- 次回予定日はいつですか。
- 誰が確認しますか。
- どのような方法で確認しますか。

回答後

```text
P
2026年8月5日に担当保健師が訪問し、
食事状況と体重を確認する。
```
