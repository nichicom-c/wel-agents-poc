# SOAP Studio 動作確認用サンプルテキスト

SOAP Studio の「SOAP 下書き生成」フォームにそのまま貼り付けて使うサンプルです。
記録種別（支援実績 / 汎用記録 / 会議 / サマリー）は分類前に選ぶものではなく、分類後に
解析結果全体（個々の候補ごとではない）に対する反映候補チェックボックス（☑/☐）として
LLM が推薦します。

## サンプル1（支援実績向け・在宅高齢者訪問）

```
本日14時に利用者宅を訪問。利用者は「最近夜あまり眠れていない、朝も体がだるい」と話す。
血圧を測定したところ152/88であった。顔色はやや青白く、受け答えはしっかりしていたが、
いつもより口数が少なかった。冷蔵庫の中身を確認したところ、食材が少なく賞味期限切れの
ものが複数あった。長女は月2回程度訪問しているとのことだが、直近1週間は来ていないと
利用者本人が話した。次回訪問時に食事状況を再確認し、必要であれば配食サービスの利用を
検討する。
```

## サンプル2（会議向け・支援会議メモ）

```
参加者：本人、長男、ケアマネジャー、地域包括支援センター職員。
長男より、本人が最近物忘れが増え、ガスの消し忘れが2回あったとの報告。本人は
「まだ大丈夫、心配しすぎ」と発言。ケアマネジャーからは要介護認定の区分変更申請を
提案。次回訪問調査は来月上旬を予定。長男は仕事の都合で平日の対応が難しいため、
デイサービスの利用日数を週2日から週3日に増やす方向で検討することになった。
決定事項は次回会議（3週間後）で最終確認する。
```

## サンプル3（低信頼度・未分類が混じりやすい断片的メモ）

```
訪問時、テレビの音が大きめ。利用者は笑顔で対応。特に変わった様子はなし。
近所の人と挨拶を交わしていたのを見かけた。次回は来月中旬の予定。
```

サンプル3 は意図的に曖昧な断片で構成しています。低信頼度の行が無理に S/O/A/P へ
分類されず UNCLASSIFIED（未分類）として扱われるかを確認するのに向いています。
